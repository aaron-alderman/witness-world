# Zoo

What exists in the canonical operator model.

## Canonical root

The root is compact and layered:

- `Things`
- `Types`
- `Relationships`
- `Commands`
- `Witnesses`

This is not the same thing as the current browse shell.

`Session` is not part of the ontology root. It is sidecar operator state.

## Current domain fan-out

The first-order domain families currently fan out beneath that root:

- `identity/`
- `core/`
- `frontend/`
- `runtime/`
- `extension/`
- `governance/`
- `evidence/`

## Read this as a zoo, not a menu

These groups are not mutually exclusive runtime menus and they are not the canonical browse root.

They are a builder-facing map of first-order objects and object families that exist in the platform.

Some are:

- semantic authoring forms
- runtime objects
- governance objects
- evidence primitives
- legacy but still real platform objects

## Important constraint

Do not treat current presentation nouns as ontology truth.

Examples:

- `screen`
- `left_screen`
- `viewport`
- `surface`
- `overlay`
- `handle`

Those are current adapter or follow-on presentation concepts, not the canonical operator root.
