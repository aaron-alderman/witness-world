# Operator Platform Gaps

## 1. Scope

Gap analysis for platform support required by the operator product.

This document is not the platform spec.

---

## 2. Current Gaps

- missing canonical product-facing document contract
- missing canonical product-facing context-pack contract
- missing platform-blessed named read models for operator consumption
- missing product-facing search contract over existing search infrastructure

---

## 3. Required Additions

- publish document catalog/read/search contracts
- publish context-pack contract
- publish named operator-facing read models
- publish product-facing search contract
- publish action-family request/result contracts

---

## 4. Decision Rule

- absence of a sanctioned read/search/doc/action contract is platform work
- use of an existing sanctioned contract is operator/product work
